# Wortliste – Quellen und Lizenz

Die Datei `target-words.json` basiert auf der Wortliste aus **Wordle-Deutsch** von George Ruinelli (GitHub: caco3), einem Fork von **typit** von Finn Coffey.

- Originalprojekt: https://github.com/caco3/wordle-de
- Original-Wortliste: https://github.com/caco3/wordle-de/blob/main/target-words.json
- Ursprungsprojekt: https://github.com/soxfox42/typit
- Lizenz: https://github.com/caco3/wordle-de/blob/main/LICENSE.md

Unsere Fassung wurde lediglich normalisiert und von Doppeleinträgen bereinigt (2030 eindeutige Wörter statt 2032 Listeneinträge).

Das Originalprojekt nennt für die Wortlisten als Quellen Wikipedia (via aaabbb.de/WordList), OpenThesaurus sowie Beiträge von Nutzenden.
